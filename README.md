# OtakuHub - منصة الأنمي الاحترافية

![OtakuHub Logo](assets/logo-otakuhub.png)

## نظرة عامة

**OtakuHub** هي منصة احترافية لمشاهدة الأنمي، مصممة لتكون منافسة قوية لتطبيقات مثل Anime Slayer و Crunchyroll. تجمع بين واجهة مستخدم حديثة وميزات قوية.

## الميزات الرئيسية

### 🌍 دعم اللغات المتعددة
- العربية (الافتراضية)
- الإنجليزية
- الفرنسية
- الإسبانية

### 👤 نظام المستخدمين
- تسجيل دخول وإنشاء حساب
- حفظ البيانات محلياً (LocalStorage)
- ملف شخصي للمستخدم
- سجل المشاهدة التاريخي

### 🎬 مشغل الفيديو المدمج
- تشغيل الحلقات مباشرة داخل التطبيق
- دعم روابط YouTube و الروابط المباشرة
- واجهة تشغيل احترافية

### ❤️ نظام المفضلة
- إضافة الأنميات للمفضلة
- حفظ المفضلة للمستخدمين المسجلين
- إدارة سهلة للمفضلة

### 🔍 البحث والتصفية
- بحث سريع عن الأنميات
- تصنيفات مختلفة
- عرض الشهيرة والجديدة والمتجددة

### 📊 إحصائيات
- عدد الأنميات
- عدد الحلقات الكلي
- متوسط التقييم
- إجمالي المشاهدات

## البنية التقنية

### التقنيات المستخدمة
- **HTML5** - هيكل الصفحة
- **CSS3 + Tailwind CSS** - التصميم والأنماط
- **JavaScript (Vanilla)** - المنطق البرمجي
- **LocalStorage API** - حفظ البيانات

### الملفات الرئيسية
```
OtakuHub/
├── index.html          # الصفحة الرئيسية
├── assets/

```

## كيفية الاستخدام

### التثبيت
1. استنساخ المستودع:
```bash
git clone https://github.com/Hicham2001965/Anime-MAD.git
cd Anime-MAD
```

2. فتح الملف في المتصفح:
```bash
# استخدم أي خادم محلي
python -m http.server 8000
# أو
npx http-server
```

3. افتح المتصفح على: `http://localhost:8000`

### إضافة روابط الحلقات

لإضافة روابط الحلقات، قم بتعديل ملف `assets/app.js`:

```javascript
const onePieceEpisodes = [
    { number: 1, title: 'مغامرة جديدة', description: 'بداية أسطورية', url: 'https://www.youtube.com/embed/VIDEO_ID_1' },
    { number: 2, title: 'الكنز الأسطوري', description: 'لقاء مع زورو', url: 'https://www.youtube.com/embed/VIDEO_ID_2' },
    // أضف المزيد من الحلقات
];
```

### تغيير اللغة
انقر على أحد أزرار اللغة في الشريط العلوي:
- العربية
- EN (الإنجليزية)
- FR (الفرنسية)
- ES (الإسبانية)

## المميزات المتقدمة

### تسجيل الدخول
```javascript
// يتم حفظ بيانات المستخدم محلياً
{
    id: timestamp,
    name: "اسم المستخدم",
    email: "email@example.com",
    loginDate: "2024-01-31"
}
```

### سجل المشاهدة
يتم تتبع جميع الحلقات المشاهدة:
```javascript
{
    anime: "One Piece",
    episode: 1,
    date: "2024-01-31T12:00:00Z"
}
```

### المفضلة
حفظ الأنميات المفضلة:
```javascript
favorites = ["one-piece", "death-note", "attack-on-titan"]
```
